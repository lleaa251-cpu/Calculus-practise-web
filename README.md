# 📐 CalcMaster 98 — 微積分線上練習系統

> 一個用 Windows 98 復古風格設計的微積分線上練習網站，讓學習不再有壓力。

🔗 **線上體驗：** https://lleaa251-cpu.github.io/Calculus-practise-web/

---

## 🎯 專題動機

微積分對我而言是一門充滿趣味的學問——把抽象公式轉換成圖形的過程讓我覺得很神奇。但身邊許多同學卻覺得它是高中數學中最難的科目。

我想做一個讓同學不那麼排斥學習微積分的工具，同時注意到朋友們對 Y2K / 復古風格很有興趣，於是決定用 **Windows 98** 的介面風格來包裝這個系統——讓人打開網頁的第一感覺是「這個介面好酷」，而不是「又要讀書了」。

---

## ✨ 功能介紹

| 模式 | 說明 |
|------|------|
| 🌱 **初學者模式** | 基礎題型 + 詳細解說 + 段落式推導步驟，無時間限制 |
| ☕ **休閒模式** | 自選主題、難度、題數（5 / 10 / 20 / 無限），支援選擇題與填入題 |
| ⚡ **挑戰模式** | 限時 30 / 60 / 120 秒完成 10 題，連擊答對最高 ×5 倍分 |
| 📅 **每日一題** | 每天一道精選題目，記錄連續練習天數 |

- 定積分
- 換元積分法

- 微積分基本定理

## 🔑 核心程式說明

### 隨機出題與洗牌（practice.js）

從題庫依主題與難度篩選題目後，使用 **Fisher-Yates 洗牌算法**將題目完全隨機排列，防止每次出題順序相同導致記憶答案的問題。

### 挑戰模式計時器與連擊加分（challenge.js）

- **倒計時器**：每秒減一，時間剩 10 秒時數字閃爍警示，歸零即結束
- **連擊機制**：連續答對一道倍率提升一級（×1 → ×2 → … → ×5），答錯歸零

## 📝 自主學習反思

這是我第一次從零建構一個完整網頁專題。過程中遇到許多問題：localStorage 資料在瀏覽器關閉後消失、上傳 GitHub 時資料夾結構錯誤導致樣式無法讀取、各 JS 檔案之間函數呼叫順序等。透過與 AI 對話、逐步拆解錯誤訊息解決這些問題，讓我真正理解了模組化架構的意義。

最有成就感的是看到朋友實際使用後覺得介面很有趣，而不是把它當成「又一個讀書工具」。這讓我確認——學習這件事，距離感少一點、趣味多一點，真的會變得不一樣。
